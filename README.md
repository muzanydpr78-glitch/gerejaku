# Website Portfolio Gereja

Stack: HTML/CSS/JS (frontend) · GitHub Pages (hosting) · Google Apps Script (backend) · Google Sheets (database)

## Panduan Singkat Pemasangan:
1. Buat Google Spreadsheet baru dan jalankan fungsi setup database di Apps Script.
2. Deploy Apps Script sebagai Web App (akses: `Anyone`).
3. Salin URL Web App ke dalam `config.js`.
4. Unggah seluruh direktori ini ke repositori GitHub Anda dan aktifkan GitHub Pages.
